## 📋 Опис

**Net Switcher** керує доступом до мережі **для кожного додатку** через правила `iptables`, якими володіє CLI `netswitcher`.

Для кожного встановленого пакета можна окремо блокувати:

| Канал | Значення |
|-------|----------|
| **wifi** | Wi‑Fi |
| **mobile** | Мобільні / стільникові дані |
| **lan** | Локальна мережа (LAN) |
| **vpn** | VPN-інтерфейси |

- Перемикайте один канал або **блокуйте все** одним тумблером.
- Зберігайте набори правил у **профілях** і швидко між ними перемикайтесь.
- Імпорт / експорт профілів у JSON для резервних копій.

Усе налаштовується з вбудованого **WebUI** або з командного рядка.

## 🔧 Вимоги

- **Root:** Magisk, KernelSU або APatch
- **WebUI:** відкривайте модуль із менеджера root (KernelSU / APatch / Magisk WebUI)
- Zygisk **не потрібен**

## 🚀 Встановлення

1. Відкрийте менеджер root (Magisk / KernelSU / APatch)
2. Встановіть модуль `Net_Switcher_*.zip`
3. Перезавантажте пристрій (бажано після першого встановлення)
4. Відкрийте **WebUI** модуля
5. Ізолюйте потрібні додатки

## ⚙️ Як це працює

| Шар | Роль |
|-----|------|
| **CLI `netswitcher`** | Застосовує і читає правила iptables; володіє `rules.conf` |
| **`rules.conf`** | Поточні заблоковані канали по пакетах |
| **Профілі** | Іменовані знімки правил (`profiles.json`) |
| **WebUI** | Список додатків, тумблери каналів, профілі та бекап |

Правила застосовуються одразу після перемикання. Активація профілю замінює поточний набір правил одним кроком.

## 🖥️ WebUI

- **Додатки:** пошук, фільтри (User / System / Isolated), чіпи каналів і тумблер «заблокувати все»
- **Профілі:** створення, активація та видалення наборів правил; поточний профіль
- **Бекап:** експорт профілів на шлях у пам’яті або імпорт з `.json` (файловий браузер у застосунку)
- **Події:** короткий журнал останніх дій isolate / allow
- **Мови:** українська, англійська та інші (`webroot/locales/`)

Відкривайте зі списку модулів у менеджері root.

## 💻 Командний рядок

```sh
/data/adb/modules/net-switcher/system/bin/netswitcher
```

Типове використання:

| Команда | Опис |
|---------|------|
| `netswitcher dump` | Показати поточні правила (`pkg=wifi,mobile,...`) |
| `netswitcher set <pkg> <канали\|none>` | Встановити заблоковані канали (`none` = дозволити все) |
| `netswitcher apply` | Повторно застосувати правила (наприклад після профілю) |

Канали — список через кому: `wifi`, `mobile`, `lan`, `vpn`.

Приклади:

```sh
# Заблокувати лише Wi-Fi
netswitcher set com.example.app wifi

# Заблокувати все
netswitcher set com.example.app wifi,mobile,lan,vpn

# Знову дозволити всі канали
netswitcher set com.example.app none

# Показати правила
netswitcher dump
```

## 📁 Конфігурація

Дані зберігаються **поза** папкою модуля і переживають оновлення:

```
/data/adb/.config/net-switcher/
├── rules.conf          # активні правила по додатках
├── profiles.json       # іменовані профілі
├── default.json        # поточний профіль тощо
└── old_profiles.json   # копія перед імпортом
```

**JSON профілю** (сучасний формат):

```json
{
  "Робота": {
    "com.example.mail": ["wifi", "mobile"],
    "com.example.chat": ["wifi", "mobile", "lan", "vpn"]
  },
  "Подорож": {
    "com.example.maps": ["mobile"]
  }
}
```

Під час імпорту також приймається legacy-формат (список повністю ізольованих пакетів).

## 📦 Структура модуля (типова)

```
📄 module.prop
📄 service.sh / post-fs-data.sh   # хуки завантаження (якщо є)
📂 system/bin/netswitcher           # CLI
📂 webroot/                       # WebUI (HTML / CSS / JS / локалі)
```

Точна розкладка може трохи відрізнятися між релізами; WebUI завжди звертається до `netswitcher` у `/data/adb/modules/net-switcher/`.

## 🛡️ Безпека

- Після видалення модуля файли модуля зникають; каталог `/data/adb/.config/net-switcher/` можна прибрати вручну.
- Правила знімаються через `netswitcher set <pkg> none` або зняттям ізоляції в WebUI.
- Вимкнення модуля в менеджері root зупиняє подальше керування (наявні iptables-правила залежно від релізу можуть потребувати перезавантаження або явного очищення).

## ⚠️ Важливі зауваження

- Використовуйте на власний ризик. Блокування критичних системних пакетів може зламати оновлення, повідомлення чи інші служби.
- Ізоляція прив’язана до імені пакета та мережевих інтерфейсів; деякі додатки можуть ходити незвичними шляхами (робочий профіль, інші користувачі).
- Краще спочатку ізолювати користувацькі додатки; з системними будьте обережні.

## 🆘 Усунення несправностей

**У WebUI «Міст WebUI недоступний»**
- Відкривайте WebUI з KernelSU, APatch або Magisk — не зі звичайного браузера й не через `file://`

**Тумблер нічого не робить / правила не тримаються**
- Переконайтеся, що модуль увімкнено і `netswitcher` на місці:
  ```sh
  ls -l /data/adb/modules/net-switcher/system/bin/netswitcher
  netswitcher dump
  ```
- Перевірте root і конфлікти з іншими firewall-модулями

**Помилка імпорту**
- JSON має бути об’єктом профілів із хоча б одним валідним правилом
- Імена пакетів — `[\w.]+`; канали лише з `wifi|mobile|lan|vpn`

**Список стрибає під час перемикання**
- Візьміть свіжий WebUI; позиція скролу зберігається при оновленні одного рядка
